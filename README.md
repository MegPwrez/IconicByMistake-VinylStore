# 🎵 Vinilooo Store

> **"Organizando la música, una venta a la vez."** 🎶

Sistema integral de gestión de inventario y punto de venta (POS) diseñado específicamente para optimizar, centralizar y agilizar las operaciones de una tienda especializada en discos de vinilo.

---

## 📌 Descripción del Proyecto

**Vinilooo Store** es una plataforma digital desarrollada para resolver las dificultades comunes en la administración manual de tiendas de música (registros dispersos, control de stock deficiente, errores de cálculo en caja y falta de segmentación de accesos). 

El sistema centraliza la información de los productos, automatiza el control de entradas y salidas en el inventario, agiliza el proceso de ventas mediante un carrito digital y protege las operaciones a través de un control de acceso basado en roles (Administrador, Cajero y Bodega).

---

## 🎯 Objetivo General

Desarrollar un sistema de software robusto que permita administrar de forma organizada y segura el inventario, las transacciones de venta y los usuarios del negocio, mejorando significativamente la eficiencia operativa diaria.

---

## ❗ Problemática que Resuelve

* **Control de Inventario:** Elimina los registros dispersos, facilitando el seguimiento de títulos, artistas, géneros y formatos.
* **Control de Stock:** Ayuda a identificar visualmente aquellos discos con pocas unidades disponibles.
* **Errores en Ventas:** Evita confusiones en los precios, cobros y existencias mediante cálculos automáticos en el punto de venta.
* **Seguridad y Accesos:** Limita y diferencia las funciones disponibles según el cargo o rol de cada trabajador.

---

## ✨ Funcionalidades Principales

1. **📀 Gestión de Inventario:** Registro, administración, consulta de títulos, artistas, precios y control de entradas/salidas en bodega.
2. **🛒 Punto de Venta (POS / Caja):** Búsqueda rápida por título o código, selección de productos, carrito con cálculo automático del total y generación de comprobantes.
3. **👥 Gestión de Usuarios y Seguridad:** Autenticación mediante credenciales con contraseñas protegidas y asignación de roles (Administrador, Cajero, Bodega).
4. **📊 Reportes y Control:** Resúmenes de ventas diarias, estadísticas de discos más vendidos y datos clave para la toma de decisiones.
5. **🔔 Supervisión de Existencias:** Monitoreo constante del estado del inventario y alertas visuales de stock bajo.

---

## 🔐 Roles del Sistema

| Rol | Responsabilidad Principal |
| :--- | :--- |
| **Administrador** | Gestionar usuarios, supervisar el sistema global y consultar reportes y datos administrativos. |
| **Cajero** | Buscar discos, procesar transacciones de venta y gestionar las operaciones autorizadas de caja. |
| **Personal de Bodega** | Consultar productos y controlar detalladamente las entradas y salidas del inventario físico. |
